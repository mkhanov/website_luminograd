В проекте использовался искусственный интеллект (Claude, ChatGPT, DeepSeek, Gemini) для решения следующих задач:
1. Генерация концептов для вдохновения
2. Генерация иллюстраций, векторных изображений для использования в презентации и на сайте
3. Решения некоторых задач по верстке (скорее по конфликтам между элемента)

Комментарий: по результатам работы с ИИ отмечен хороший уровень генерации изображений, но при этом часто ошибочные и не самые
удобные решения в верстке
